# 📰 İSTE Haber Portalı & Gazepoint Eye-Tracking Entegrasyonu

İskenderun Teknik Üniversitesi (İSTE) için geliştirilmiş Flask tabanlı dinamik haber portalı ve UX (Kullanıcı Deneyimi) araştırmaları için Gazepoint Control / Analysis göz takip cihazı entegrasyonu projesidir.

---

## 🛠 Kullanılan Teknolojiler ve Programlama Dilleri

### 💻 Programlama Dilleri & Web Teknolojileri
- **Python:** Flask Framework, Web Scraping (BeautifulSoup, Requests), Veri Analizi ve Soket İletişimi
- **JavaScript (ES6+):** Asenkron Veri İşleme, WebSockets / EventSource, Dinamik DOM Manipülasyonu
- **HTML5 & CSS3:** Responsive Arayüz Tasarımı ve Bileşen Mimarisi
- **C# & C++:** Masaüstü Otomasyonlar ve Algoritma Temelleri
- **SQL:** İlişkisel Veritabanı Sorgulama ve Yönetimi

### 🗄 Veritabanı Sistemleri
- **SQLite:** Yerel Veritabanı Yönetimi ve Python Entegrasyonu
- **MySQL:** İlişkisel Veritabanı Mimarisi

### 🧪 UX Research, Neuro-Marketing & Donanım Entegrasyonu
- **Gazepoint Control (Open Gaze API v2.0):** `4242` Portu Üzerinden Anlık Bakış Koordinatları Dinleme
- **Gazepoint Analysis:** Ekran Kaydı (`Screen Capture`), Isı Haritası (`Heatmap`), Odak Alanı (`AOI - Area of Interest`) ve Bakış Yolu (`Fixation Path`) Analizi

### 🧰 Geliştirme Araçları & Ortamlar
- **IDE & Editörler:** Visual Studio Code, Visual Studio
- **Versiyon Kontrol:** Git, GitHub Desktop, GitHub
